1.1.1     CLASS /RB4R/MM_CL_SOURCE_LIST.

Method CONSTRUCTOR.

Select EROD data and create object with reference to the class /RB4R/MM_CL_SRCLST_ENTRY for the EORD data.

Method PROCESS_DATA.

This method calls the below methods to display the ALV output.

SET_DEFAULT_ATTRIBUTES

BUILD_TEMPLATE

GET_DATA_REFERENCE

CREATE_OUTPUT

DISPLAY_OUTPUT

Method CREATE_OUTPUT.

Performs creating dynamic internal table and assign the values and calls the below methods.

VALIDATE_LIST

AUTH_CHECK_ENTRIES

CHECK_ERROR_EXIST

Method DISPLAY_OUTPUT.

It performs to display the data using custom container reference CALL METHOD  set_table_for_first_display

Method GET_FIELD_VALUE.

Get the field value of the respective field in the structure.

Method Toolbar_action.

This method performs the creation of custom buttons in the ALV output as shown below.

Method User_command.

This method performs the handling of toolbar buttons (user command e_ucomm ).

Method Download.

This method performs the handling of downloading of source list ALV data to Excel format with the same display and field attributes as per the customization settings. It uses the class /RB9S/PROC_CL_XL_EXCEL.

Method Output_excel.

This method performs to download the excel file to the specified path using method DOWNLOAD_EXCEL_FRONTEND.

Method double_click.

This method performs the click navigation on the ALV field STATUS to get the log information.

Method HOTSPOT_CLICK.

This method performs the click navigation on the ALV fields – Material,Vendor ,agreement and Info record number.

Method VALIDATE_LIST.

It performs the validation of the source list data including group validations and single source list entries using the below methods.

VALIDATE_PERIODS

VALIDATE_MULTIPLEPURCHDOC

VALIDATE_AUTET

VALIDATE_FEBEL

VALIDATE_FLIFN

VALIDATE_FRESW

Method DATA_CHANGED.

This method performs the handling of data changed event in the editable alv fields. It also does the below functions

  • Set the ROW CHANGED indicator for each changed row.
  • Update the changed cell
  • Create local object entry to get the messages after changing the line
  • Add Log to the error table
  • Set the action
  • Call method Process_data

 Method Upload.

This method performs the handling of uploading of source list ALV data from Excel format with the same display and field attributes as per the customization settings. It uses the class /RB4R/MM_CL_XL_EXCEL.Also Performs the below fuctions.

  • Get the database entries for the selection screen parameters from the uploaded excel file by creating the local object with reference to the class /RB4R/MM_CL_SOURCE_LIST.
  • Build internal tables mt_entry_embed,mt_eord_embed and calls method EMBED_ENTRY_XLS.

Method POPUP_UPLOAD_MODE.

Call popup using function module /RB4R/MM_SRCLST_UPLOAD_MODE to perform the below functions:

  • Delete existing database records
  • Close existing database records
  • Keep database records unchanged

Method PROPOSALS:

It is used get proposals from inforecords or outline agreements using the below     function modules

          /RB4R/MM_SL_FROM_INFOREC

          /RB4R/MM_SL_FROM_OUTL_AGRMT

Method SAVE_SOURCE_LIST.

It performs the save function based on the action id and uses the below methods

SOURCE_LIST_DELETE

SOURCE_LIST_INSERT

 SOURCE_LIST_UPDATE

      The function modules ENQUEUE_EMEORDE and DEQUEUE_EMEORDE

       to lock the source list entry during saving.

 Method SOURCE_LIST_UPDATE

This method performs the updation of the changes in the existing source list record for the action code ‘U’ in the ALV using function module ME_UPDATE_SOURCES_OF_SUPPLY.

Method SOURCE_LIST_INSERT

This method is used to INSERT the new source list record for the action code ‘I’ in the ALV using function module ME_UPDATE_SOURCES_OF_SUPPLY.

Method SOURCE_LIST_DELETE

This method is used to DELETE the existing source list record for the action code ‘D’ in the ALV using function module ME_UPDATE_SOURCES_OF_SUPPLY.

Method SET_DELETION_FLAG

It is used to set the action code ‘D’ on the toolbar action ‘DELETE’ for the selected    lines in the ALV .

Method POPUP_SAVE_CONFIRM

It performs calling popup to confirm the SAVE function for the changed lines before moving to another functions.

Method SET_ACTION

It is used to set the ACTION code for the source list entry.

Method EMBED_ENTRY_XLS

It is used to embed the new entries which are received during upload function into existing database entries.

Method EMBED_ENTRY_PROPOSALS

It uses to embed the new entries into existing database entries based on the selected option.

Method GET_SOURCELIST_ENTRY

                        To check if any source list entry exists for the passed key fields.

           

Method CHECK_ERROR_EXIST

To set red cross symbol in the status field if any error exits for the key combination matnr,werks and ekorg.

Method MENU_BUTTON

This method performs the creation sub-menu options for the main menu buttons Delete and Proposals.

Method SET_FIX_SOURCE_INDICATOR

This performs setting the fix source indicator for the source list entry based on the values of EBELN,LIFNR and  RESWK.

Method AUTH_CHECK_ENTRIES

It performs authorization check on organization level.

Method AUTH_CHECK_TCODE

It performs authorization check on tcode ME01.

Method VALIDATE_AUTET

It is used to check if the material planning is unique and pass the error message.

Method VALIDATE_FEBEL

It performs the validation for the fixed source indicator if outline agreement is assigned.

Method VALIDATE_FLIFN

It performs the validation for the fixed source indicator on vendor level.

Method VALIDATE_FRESW

It performs the validation for the fixed source indicator on supplying plant level.

Method VALIDATE_MULTIPLEPURCHDOC

It performs the validation if the same purchasing document is assigned to multiple source list entries.

Method VALIDATE_PERIODS

It performs the validation on the over lapping periods of the source list entries.

Method VALIDATE_GROUP_PERIODS

It performs the validation check for source list groups for which the validity periods needs to be considered.

Method BUILD_FIELDCATALOG

It performs preparation of field catalog for the ALV output.

Method ADD_MESSAGE

This method is used to add the messages to the error log internal table of the each source list entry.

Method GET_FIELD_ATTRIBUTES

It is used to get the field attributes for the ALV output.

Method GET_DATA_REFERENCE

It is used to get data reference for alv source , excel source based on the source list maintenance class /RB9S/PROC_CL_SOURCE_LIST class reference.

Method PUT_LOG

This method performs the collect and prepare of return messages for status log. It belongs to return message type BAPIRET2.

Method GET_ALV_VARIANT

It is used to set variant for the ALV output

To exclude the functions in ALV output screen.

To perform ALV layout settings

It is used to set default attributes for the ALV output.

1.1.3     Function Group: /RB4R/MM_API_SOURCE_LIST

RFC - /RB4R/MM_API_SOURCELIST_READ:

It is used to read the source list data for the input received via import parameters.

Build the selection screen internal table with the values received via import parameters.

Create Source list object with reference to the class /RB4R/MM_CL_SOURCE_LIST for the selection screen internal table values.

Call method VALIDATE_LIST to do the group validation.

Call method CHECK_ERROR_EXIST to set CANCEL icon to the remaining entries in the group if any error exists.

Export source list data via exporting parameter.

            RFC - /RB4R/MM_API_SOURCELIST_SAVE

                        It is used to save the source list data.

Build the selection screen internal table with the values received via import parameters.

Create Source list entry object with reference to the class /RB4R/MM_CL_SRCLST_ENTRY for the EORD data.

Create Source list object with reference to the class /RB4R/MM_CL_SOURCE_LIST for the selection screen internal table values.

Check if any database entries available for the input data and move to general tables EMBED and DB.

Call method EMBED_ENTRY_XLS from source list object to embed the new entries into the existing entries on database by setting the action code.

Call method VALIDATE_LIST to do the group validation.

Call method CHECK_ERROR_EXIST to set CANCEL icon to the remaining entries in the group if any error exists.

Call Method SAVE_SOURCE_LIST to save source list.

1.6      Phase out concept

Phasing out this product is pretty straightforward, as it works completely on its own namespace, having all associated objects in a single package. In order to decommission this product, phase-out (technically deletion) transports prepared in CD system have to be imported to the target system.  To completely delete the product from the system, it would require a deletion transport from DC7 system. This deletion transport must include all the objects of the objects for the respective version of the tool.

Please note that if any development or enhancement implemented locally in target system on top of this CD product, all of them have to be removed from the target system before importing the phase-out transports.
