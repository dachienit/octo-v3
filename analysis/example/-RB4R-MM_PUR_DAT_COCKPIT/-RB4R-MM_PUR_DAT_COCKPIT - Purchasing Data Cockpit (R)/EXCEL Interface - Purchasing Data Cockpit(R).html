1.1      Package hierarchy

This package: /RB9S/PROC_XLSX_FROM_ABAP is a utility package for Excel~ABAP interface generate Professional Excel spreadsheets directly from ABAP. There are no sub packages designed.

The package is a sub-package of the main package /RB9S/PROC_PUR_DAT_COCKPIT.

1.6      Phase out concept

Phasing out this product is pretty straightforward, as this is an independent SAP solution. It works  completely on its own namespace, having all associated objects in a single package. In order to decommission this product, phase-out (technically deletion) transports prepared in CD system have to be imported to the target system.


Please note that if any development or enhancement implemented locally in target system on top of this CD product, all of them have to be removed from the target system before importing the phase-out transports.
